# Evidence and remaining acceptance

Status: MVP, 1 November 2026. All demonstration data is fictitious.

The browser suite passed 10 rendered workflows. TypeScript passed 64 tests; Kotlin
passed 24 tests, including the 36-row shared policy contract. Private source CI
also passed browser and Android build jobs.

In Android API35 emulation, an actual notification from the signed owned source
created a request. UI automation produced BK-RLY-1044 in the native reference store.
A second overlapping attempt became SLOT_CONFLICT and the store remained at one.
The recorded next-day request produced BK-RLY-1043 through the native form.

A separately selected generic owned test source was ignored before consent and
selection, then stored one request while MainActivity was in background. Its
received content lacked service/date/time, so it remained in review. This verifies
background intake and conservative review, not reading hidden notification content.
The exact cause of unavailable details was not established. Android documents
[restrictions on sensitive notification content](https://developer.android.com/about/versions/15/behavior-changes-all).
Pausing prevented the next OS notification from creating a request.

The final signed release packages were installed as updates. The interface retained
the two confirmed synthetic records. Release debugging is disabled. No own-package
fatal Android exception was found in the inspected emulator log.

Physical phones/OEM background behaviour, customer demand, real third-party adapters,
commercial operations and store review remain separate work. No security protection,
lock screen or platform permission was bypassed for this demonstration.
